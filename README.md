# Elias Teikari

A plain HTML portfolio built with Next.js. The page uses semantic HTML and the browser’s default appearance, with no CSS, custom fonts or animations. A portrait appears below the name.

## Development

```sh
npm install
npm run dev
```

Open http://localhost:3000. Edit the portfolio content in `src/app/page.tsx` and metadata in `src/app/layout.tsx`.

## Checks

```sh
npm run lint
npm run build
```

Run `npm start` to serve the production build.
